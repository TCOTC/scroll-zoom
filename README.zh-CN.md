# 滚轮缩放字号

按住 <kbd>Ctrl</kbd>，用鼠标滚轮或触控板捏合，即可调整思源编辑器字号。改动走思源原生接口，与在设置里改编辑器字号效果相同。

适用于桌面端、桌面端独立窗口、浏览器桌面端。

## 用法

在编辑器内容区域操作：

- **鼠标**：按住 <kbd>Ctrl</kbd>，向上滚动放大字号，向下滚动缩小字号
- **触控板**：按住 <kbd>Ctrl</kbd> 后双指上下滑动；或直接双指捏合 / 张开（浏览器会把捏合映射成带 <kbd>Ctrl</kbd> 的滚轮事件）

字号范围为 **9–72**，与思源编辑器设置一致。

## 说明

- 必须从按下 <kbd>Ctrl</kbd> 之后开始这一轮滚动，中途再按无效。触控板惯性会在松手后继续产生滚轮事件，这样可避免划动后再按 <kbd>Ctrl</kbd> 误调字号
- 上一轮滚动结束后，需间隔约 200ms 再按 <kbd>Ctrl</kbd> 滚动，才会再次调整字号
- 横向滚动不会改字号
- 仅调整编辑器字号，不缩放界面
